# VRPhys

VRPhys — мод для NeoForge `1.21.1`, который связывает VR-трекинг, физику движущихся пространств Sable и иммерсивные взаимодействия Minecraft.

Цель проекта — сделать полноценную прослойку между Vivecraft, Sable и будущей физикой VR-взаимодействий: корректные координаты рук/игрока в движущихся саб-уровнях, безопасные distance-checks, учёт скорости платформ и точка расширения для ImmersiveMC.

## Что уже подключено

- `sable-companion` `1.6.0` встраивается в jar через JarJar. Его безопасная реализация работает даже без установленного Sable.
- Vivecraft подключён как optional dev-зависимость. В коде используется reflection-bridge, поэтому VRPhys не падает, если Vivecraft отсутствует.
- ImmersiveMC определяется как optional-интеграция. Прямая регистрация иммерсивов будет следующим этапом, когда появится конкретная механика VRPhys.
- GitHub Actions собирает мод на сервере и прикладывает jar как artifact.

## Сборка

Локальная сборка не обязательна. Основной путь — пуш в GitHub:

```bash
git push
```

После пуша GitHub Actions выполнит:

```bash
./gradlew --no-daemon build
```

Готовые jar-файлы будут доступны в artifacts workflow `Build`.
